# cl-audio-kit

cl-audio-kit provides blocking audio output through PortAudio from Common Lisp. Its in-memory recording device supports tests and applications that need to inspect samples without opening hardware.

## Start here

- [Getting started](getting-started.md) loads the system in the Nix development shell.
- [Manual audio check](guide/manual-audio-check.md) plays a one-second 440 Hz tone through the default output device.
- [API reference](reference/api.md) describes output streams and the recording device.
